# Airo Homebrew tap

The [Homebrew](https://brew.sh) tap of the Airo platform's tools.

```sh
brew install airohq/tap/airo
brew upgrade airo
```

| Cask | Tool |
| --- | --- |
| `airo` | [airo](https://github.com/airohq/airo-cli), the command-line tool of the Airo platform |

The casks in `Casks/` are written by each tool's release. Do not edit them by hand.
